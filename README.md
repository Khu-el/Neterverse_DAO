## 🌐 Network

This portal is one property in a wider set. It is **not currently hosted on a domain** — the page
is served from this repository, and no hostname on `excellencedistrict.org` points at it. The
canonical map of what runs where lives in one place, in the sibling repo, rather than being
restated here:

- [Domain property map](https://github.com/Khu-el/Khu-el/blob/main/docs/DOMAIN_NETWORK.md) — every
  hostname across the three repos, what is verified, and what is still only planned.
- [Connector & plugin registry](https://github.com/Khu-el/Khu-el/blob/main/docs/CONNECTORS.md) —
  every available integration and what each one may not do.

Two boundaries carry over unchanged. Sharing a network is a hosting fact, not a merge: the private
Lane B estate records in the sibling repo do not belong here, and nothing moves from there to this
public-facing repo. And publishing, filing, serving, or recording anything drafted here remains a
human decision under §10 — a page linking to this repo is not authorization to publish what is in
it.
